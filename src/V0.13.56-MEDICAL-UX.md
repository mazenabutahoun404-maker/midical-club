# MedClub V0.13.56 — campus, direct learning and mobile PDF reading

This is a complete replacement `src` folder built on V0.13.55. Keep the existing project configuration and dependencies; this update adds no package dependency.

## Implemented

- The public homepage uses the supplied three-building Learning / Media / Community campus. Optimized 960px and 1672px WebP variants include a matching night scene. Its links, paths and lighting target these three buildings. Baked English signs are retained; Arabic uses localized sign overlays with the mirrored scene. Whole-campus footer backgrounds use the same new artwork. Auth and personal campus sequences retain their existing six-building configuration.
- `/learn` opens a searchable course directory directly. Search supports bilingual names, course codes, Arabic marks and Arabic digits. Pathway, year and batch are optional filters; shared-batch membership is included. Search/filter state is stored in the URL. The previous pathway/batch browsing remains available below the directory. Catalog routes reuse the directory, and book cards retain their natural size with 12 initially displayed.
- Phone PDF readers start at page width and expose zoom out, 100% reset, zoom in and Fit width without opening the tools menu. Whole-page fit remains available. Two-finger gestures preview a CSS transform and commit zoom once; one-finger native scrolling is preserved. Pinching is guarded against creating a margin note. The PDF opening effect and fixed raster size are unchanged.
- Navigation defaults to pinned when there is no saved choice. An explicit saved unpinned choice is respected. Guests can collapse the sidebar without unlocking signed-in palettes. Existing PDF/exam focus behavior remains.

## Deliberately awaiting discussion

No broader palette redesign, anatomical decoration, phone navigation redesign or new auth scene has been implemented. Those are proposals for the next decision, as requested. Existing exams, API services, authentication and personal dashboard behavior remain included.

## Validation

- Strict TypeScript checking and a production Vite build pass.
- Fourteen component-test groups pass with no captured console errors: bilingual course searching and shared batches, optional-feed recovery, three-building maps, pinning/collapse persistence, focused-course chrome, course pagination, and PDF controls/gestures at simulated 390px and 1024px widths in both languages.
- Instrumented PDF tests confirm one document open and one source-raster size across zoom actions. The test uses an engine adapter; it does not benchmark a real document download or PDF.js rendering.
- Browser layout, artwork/sign alignment, touch behavior on real iOS/Android hardware, and visual theme acceptance were not verified in a browser in this session. Synthetic DOM checks do not establish those results. Check these before deployment.

## Integrate

Back up the current source, replace the complete `src` directory, then run the existing project typecheck/build. No deployment or API connection is included in this release.
