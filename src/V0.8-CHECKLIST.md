# MedClub V0.8 integration checklist

## Replace and build

- Back up the current `src` directory, then replace it as one unit.
- Keep the existing dependency and Vite/Tailwind configuration.
- Run TypeScript checking, the full automated suite and the production build.
- Confirm the browser console has no MedClub source exceptions.

## Account flow

- Open a protected `/my/*` URL while signed out and confirm sign-in appears.
- Use the preview account and confirm the originally requested route opens.
- Register a second account, verify it with `260908`, edit the profile and reload.
- Sign out and confirm personal routes close.
- Confirm recovery gives the same response for known and unknown emails.
- Test a second tab and confirm account changes synchronize.

## Visual and accessibility acceptance

- Test WebGL in current Chrome, Safari and Firefox plus a device without WebGL.
- Enable reduced motion and confirm the field becomes static.
- Complete every auth action using only the keyboard.
- Test zoom, narrow mobile widths, landscape tablet and Arabic RTL.
- Confirm focus is visible, error messages are announced and controls stay at least 44px where practical.

## Navigation repair

- Check expanded and collapsed public rails in vertical and horizontal modes.
- Confirm no native scrollbar is visible but wheel, touch and keyboard scrolling work.
- Confirm overflow shadows change at the start, middle and end.
- Check every personal destination remains contained in the rail.
- Open the desktop mega menu near each rail edge and confirm it is not clipped.

## Before production accounts

- Replace the local adapter with a server-backed identity service.
- Use secure HttpOnly sessions or an approved identity platform.
- Add CSRF defense, email verification/recovery delivery, expiry, throttling and lockouts.
- Decide university-email eligibility, privacy, retention and account deletion policies.
- Enforce roles/capabilities and protected data on the server with audit history.
