# MedClub V0.13.32 — Requested themes and motion

This release updates the accepted V0.13.31 sources. Replace the complete `src/` folder and keep your existing project configuration and dependencies. No dependency was added.

## Requested changes

- Added Sage, Midnight and Espresso, each with light/dark definitions, bilingual labels, preview colors and matching PDF theme-paper/ink colors. The existing themes and stored preference keys are preserved.
- Removed Appearance from the public and admin headers. It remains in the navigation, including horizontal navigation; phone More menus provide the same setting after removing its header entry.
- Restored wine administrative navigation/header surfaces in MedClub Light. The admin content panels remain light. Hover, selection, control and focus colors follow the wine navigation role.
- Hidden pin/hide controls reserve no width, height or associated gap. The space returns on hover or keyboard focus. Touch controls remain revealed; collapsed controls stack and horizontal footers use their actual visible width.
- Centered the admin operation signal between equal outer header columns. The admin profile entry contains only its named icon. Narrow signal text truncates with its full label retained for accessibility and the tooltip.
- Added a brief bell hover/focus movement and a single restrained arrival movement for newly seen notification IDs. First load, reordered/unchanged IDs, read-status-only changes, refetches and account changes do not generate false arrival movements. Existing notification fetching and read behavior are unchanged.
- The existing study overview progress indicator now has a smoothly transitioning visual fill backed by native accessible progress semantics and the same actual completion counts. RTL fills from the opposite edge.
- Theme changes briefly fade colors on the existing application chrome and appearance controls. The fade animates background/text/border colors only, without screen overlays, opacity flashes or replacing existing transform animations. First mount does not fade. Unsupported animation APIs fall back to the selected theme immediately.
- Refined the shared bookmark icon morph with a quick fold-and-fill response. The save button and its flight to the library are outside that morph scope and are preserved unchanged.
- The requested new motion respects reduced-motion preferences. Notification/theme animation resources are canceled on unmount and when reduced motion is enabled.

## Verification and limits

- Passed 35 executable logic checks using the actual TypeScript helper modules for notification arrival tracking/animation, progress values, color-only theme fading and new palette metadata. Native type stripping executes these helpers; it is not a full TypeScript type check.
- Checked 270 semantic color pairs across all 18 light/dark variants. The checked text pairs are at least 4.57:1; the checked input/focus pairs are at least 3.07:1. Preview and dark PDF palette colors match the semantic definitions.
- Checked five additional wine navigation role pairs: readable text, selection, boundaries and focus. These checks cover defined color pairs, not every rendered element or composited background.
- Checked 65 relative imports in affected modules, stylesheet structure/import order, 28 conservative centered-admin-header sizing models from 320–2560px, header appearance removal, and preservation of navigation access to Appearance.
- Confirmed the save-flight component, its motion stylesheet, library destination navigation components and the existing shared icon component are byte-for-byte unchanged from V0.13.31. New bookmark CSS is scoped to the shared morph wrapper and does not target the save button or flight.
- All 767 files from V0.13.31 are retained. Changes are limited to the requested themes, header/navigation fixes, named motion, necessary component wiring, and release metadata/documentation. Services, routes, permissions and business records are unchanged.

Full project TypeScript checking, Vite build, existing application regression tests and real-browser/device visual QA were not run. The supplied archive contains only `src/`, and the complete build setup and an installed browser are unavailable here. Run your configured project's checks and inspect theme switching, centered admin chrome, hidden/revealed controls, new notification arrivals, study completion, bookmark morphs and the preserved library save flight before deployment.
