# V0.3 design extension

The V0.1/V0.2 identity is preserved: warm paper surfaces, red/russet accents, local typography, curved cards, collapsible desktop navigation, phone dock, academic passports and course atlas.

V0.3 adds a distinct layout for each personal task:

- **Dashboard:** an asymmetric resume card with layered orbit lines, an explicit review-marker meter, a date rail and two recent-activity columns.
- **Library:** a collection rail and tactile card shelves. Mobile moves the rail above the saved content. The same resource/event/opportunity cards are reused.
- **Calendar:** a keyboard-operable month table paired with a persistent agenda; mobile stacks them rather than shrinking the desktop layout.
- **Search:** visible scope/metadata filters and grouped results with match explanations. The command interface becomes the full search page without a second search implementation.
- **Notifications:** a chronological stream with explicit read/unread controls; styling changes when state changes.
- **Phone personal navigation:** Home, Learn, Saved, Calendar and More. More contains the remaining personal tools. Notifications also remain available from the header.

Hover feedback uses short upward movements, border shifts and warm surface changes. There is no scroll hijacking, delayed navigation or fabricated productivity score. The existing reduced-motion rules disable animation/transition globally; the new stylesheet also protects its own interactions.

Native dialogs preserve the existing curved surfaces while placing overlays in the browser's top layer. Public navigation and personal settings use the same corrected modal lifecycle.

A real-device visual acceptance pass is required before calling this design finished.
