# MedClub V0.13.30 — Appearance comfort

Replace your existing `src/` directory with the complete `src/` folder in this archive. Keep your existing project configuration and dependencies. No dependency was added.

## Appearance changes

- The default light theme uses warm off-white pages, quiet neutral navigation and softer card surfaces. MedClub red remains on primary actions, selected-item indicators and brand accents.
- The default dark theme uses charcoal surfaces, soft light text and restrained rose accents. Decorative borders are quieter; input boundaries and focus indicators remain stronger.
- Paper, Dusk, Tokyo and Solarized retain separate identities in both light and dark modes, with less saturated surrounding surfaces. The explicit high-contrast palette definitions are retained unchanged.
- Public, personal and admin navigation use the selected palette consistently. Large chrome gradients, page-level ambient gradients and the admin shortcut's glow are removed. Existing layouts, navigation movement and controls are preserved.
- Appearance choices have softer corners and clearer selected states. Their swatches and illustrative previews match the final semantic palette colors.
- PDF theme-paper colors match the updated palette surfaces. PDF rendering, original-color mode, saved documents, diagrams and reader functionality are unchanged.
- The new appearance layer excludes OS forced-color mode, preserves existing reduced-motion behavior, and strengthens borders when increased contrast is requested.

## Scope

Changes are limited to theme styles, appearance palette metadata and previews, the displayed version, and these release notes. All 761 original source files are retained. Routes, services, storage keys, permissions, content records, components and application behavior are unchanged.

The shared appearance treatment is imported last in `styles/index.css` as `styles/appearance-comfort-v1330.css`. Palette definitions remain in `styles/tokens.css`, `styles/dark-palette.css` and `styles/reading-palettes.css`.
