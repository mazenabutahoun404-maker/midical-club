# MedClub V0.13.27 — Study Hub

This release adds PDF margin notes, recall practice, offline course packs, an evidence-backed campus portfolio, and quiet study rooms. Every V0.13.26 source file is retained. The previous study environment, theme system, PDF controls, role separation, personal navigation and activity routes remain included. No Connected Learning Materials system was introduced.

## How to try it

Sign in, then open **Your study desk** from the personal dashboard or the existing Focus page. The sidebar still has 12 destinations.

- **Margin notes:** open a real course PDF → PDF tools → Margin notes. Add a note on the active page, or choose Place on PDF and tap a point/select text. Notes are private, versioned and anchored to the file revision. Convert one into a recall card from the note panel. Closing the panel restores the full PDF space.
- **Recall:** `/my/study/recall`. Create a course question/answer or use a margin note. The answer stays hidden until revealed; Again/Hard/Good/Easy schedules the next review. View/edit your cards, delete with Undo, and keep self-ratings distinct from exam results.
- **Offline packs:** `/my/study/offline`. Choose a course with real PDF files, or add a personal PDF to the private pack. Download stores actual Blobs in account-scoped IndexedDB; progress/cancel, checksum/expiry checks, complete-pack replacement and remove/Undo are supported. Open the downloaded PDF from the pack. Notes/cards are read-only download snapshots. Cold offline launch requires the supplied build step below.
- **Portfolio:** `/my/portfolio`. Create an evidence-backed achievement, submit it, and let a distinct authorized reviewer verify it. Publications use content-review access; other campus records use event-management access in the preview. Reviewers can revoke verification. Sharing starts off; explicit consent enables a link containing only name and verified achievements. It excludes private notes, pending claims, internal owner/reviewer IDs and evidence URLs. Local attestations are not institutional certificates.
- **Quiet rooms:** `/my/study/rooms`. Create a room or join with an invite, set a goal, and use the host-controlled focus/rest clock. Capacity is enforced; membership is required to read a room. Presence is based on real local accounts, not invented students. The host leaving finishes the room. The local preview only connects accounts inside this browser.

The new delete controls reuse the existing paper-to-bin effect after the service confirms deletion. Notes/cards/claims/packs support Undo where appropriate; reduced-motion handling remains in place.

## API connection

Read `integration/BACKEND-ADDITIONS.md` and the separate handoff first. It compares the features with all 12 pages of the original requirements document and separately lists older additions that may need backend coverage.

`MedClubServices.studyHub` accepts the typed service in `types/study-hub.ts`. `services/study/http-study.service.ts` implements the proposed contract with auth/CSRF callbacks, request/response mapping, encoded IDs, bounded cursor pagination, version headers, idempotent recall attempts, request cancellation and runtime response checks. `integration/connect-study-hub.ts` composes it with your existing backend adapters.

The OpenAPI file documents 33 proposed operations and 35 schemas. These are not confirmed routes from the existing backend. Supply the actual API specification for a mapping review. The adapter also supports private PDF upload so API-backed margin notes can use stable owned file IDs; it never grants course publishing access.

A live content registry without this adapter reports an unavailable Study Hub service instead of silently using the preview store. Older local helpers for general notes, study state, tool state and appearance preferences still require their own backend sync mappings; these are identified in the handoff rather than disguised as connected services.

## Offline hosting setup

After your normal frontend build, run:

```bash
node src/integration/offline-build.mjs dist
```

Serve generated `dist/medclub-sw.js` at the origin root as JavaScript, over HTTPS or localhost. Keep it out of the SPA HTML fallback. It caches only the static app shell/assets, never private API/PDF requests. The backend auth adapter must define the approved offline-session policy. The source-only archive includes the build helper; add the step to the project's CI/package scripts.
