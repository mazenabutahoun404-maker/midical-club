# MedClub V0.13.28 — workspace and reading corrections

Install by replacing the entire `src/` directory with this archive's complete tree. This is a source-only handoff, with no new runtime dependency. V0.13.27's five study additions and the earlier product modules are retained.

## Changes

- Downloaded PDFs open in a viewport-sized native dialog, with a dedicated title/close row and the existing PDF renderer underneath. Removing the inherited modal translation fixes the off-screen origin in the reported screenshot. Internal PDF zoom/pan and theme paper controls remain available. Offline reading does not trigger online margin-note requests; the pack's saved note/recall snapshot remains accessible from its card.
- Private pack files use the same validated multi-file drop zone as course publishing. The shared component accepts localized copy so a private staging file is never described as published. Drop, landing, progress, failure and success states are retained. After a completed pack save, a 1.4-second success receipt ends in a reset course/file/progress form; the saved pack remains. Failed or cancelled downloads retain staging files for retry. Staged and opened-file object URLs are revoked when finished, changed or unmounted.
- The personal sidebar has ten destinations. Study Insights is a secondary view under My Learning (`/my/learning?view=insights`), loaded only when opened. `/my/progress` redirects there. The old Settings route remains valid, but its sidebar destination is removed. Appearance now includes compact-sidebar and language controls, while retaining all theme palettes/previews and layout preferences. Appearance is available from the sidebar and phone More menu; its duplicate personal-header shortcut is removed.
- Search and notification positions are exchanged. The bell opens a collision-aware popover anchored to its button; opening it does not enter My Room. It shows real notification data, unread state, loading/error recovery and an explicit full-notifications link. Resource/item actions retain their intended destinations. Escape, outside click and route changes close the popover.
- Pin/hide controls use a dedicated navigation tray and cannot cover destination or appearance controls. Pointer hover and keyboard focus reveal them; touch users retain access. The Admin shortcut stays capability-gated, in a compact position beside the profile footer, with its phone More shortcut retained.
- Sign-out uses independently moving door/person SVG parts on hover/focus, with pending feedback and reduced-motion support. Existing authentication and workspace transitions are retained.
- Course sections use horizontal paper bookmarks in browse and focus modes, including legacy saved vertical settings. The unused orientation toggle is removed from the tool strip. A separate 44px section row/close slot keeps section close and PDF close controls in different rows. Phone bookmarks retain 44px targets. Browse-mode centered book gutters and PDF internal scrolling are preserved.

## Backend handoff

This release changes UI composition and layout; it adds no API operation. Existing notification/workspace, academic-insight, course and study-hub service interfaces are reused. The V0.13.27 backend additions summary and proposed OpenAPI remain in `src/integration/`. They still require mapping to the actual backend contract before production connectivity is claimed. Student private imports remain distinct from permission-gated course publishing.

Offline app launch still requires the supplied post-build step: `node src/integration/offline-build.mjs dist`, serving the generated root service worker with a JavaScript MIME type. Merely replacing `src/` cannot enable offline cold launch on the host.
