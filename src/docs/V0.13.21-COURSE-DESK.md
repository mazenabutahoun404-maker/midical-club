# MedClub V0.13.21 — Persistent course desk and leather shelf

This release starts from the complete V0.13.20 source. Keep the existing installation and replace its entire src directory with the src directory in this archive. No runtime dependency was added.

## User-facing changes

- Equal-width header shoulders center the course shelf independently of the course title and utility controls. The current course name stays beside the back control on desktop; narrower screens keep compact controls.
- A short beveled ledge, subtle supports and course-colored leather cover edges replace the long divider. Desktop books expose about 10 px at rest (14 px for the selected book), revealing their title on hover or keyboard focus. Touch targets retain a readable 44 px portion without requiring hover.
- Learn retains direct navigation to Explore courses and its hover category panel. A static, separately operable dropdown chevron sits beside the book icon and stays visible in collapsed navigation.
- Fine-grained and smooth leather materials follow the existing course colors. Texture belongs to the cover and binding; the reading paper and PDF remain unchanged.
- Course-to-course navigation in one workspace keeps the desk header, shelf nodes and scroll position mounted. Only the reader and course-scoped tools reset, restoring their saved state. Catalogue navigation and transitions between workspaces keep their existing route transitions.
- The shelf handles 50 courses in a bounded horizontal viewport, with mouse/pen dragging, native touch scrolling, paging arrows and directional keyboard controls. Home/End reach the first/last book. Drag release cannot accidentally open a course; ordinary clicks still navigate.
- The selected book is revealed only if it moves outside the visible shelf. Focus mode continues to show the notebook and study tools while hiding the header.

## Extension points

CourseDeskHeader.tsx separates persistent chrome from the keyed reader in StudyEnvironment.tsx. Reader controls register against the current book, so split view cannot mutate a previous course after switching. The stable context avoids extra reader updates when control registration changes.

CourseShelf.tsx derives all links from the existing course, batch and clinical-year services through shelfCourses; no fixed 50-course limit or sample inventory was added. The viewport, arrow distance and overflow cues respond to its measured size. Resizing keeps the current course reachable, and course/account study storage keys remain unchanged.

For a much larger catalogue, add a searchable course picker and explicit year/term filters through the existing content-service boundary. If inventories grow to hundreds or thousands, add server paging before introducing virtualization; preserve normal links, keyboard access and selection visibility.

## Generated material assets

Built-in image-generation mode was used. Final assets are included at:
- src/assets/materials/leather-pebbled.webp (31,118 bytes)
- src/assets/materials/leather-smooth.webp (13,912 bytes)

Both are shared 384 × 384 WebP material tiles. The background overlay is restrained to 8%; it is removed in forced-color mode.

Pebbled material prompt:
Use case: product-mockup. Asset type: repeatable material texture for a responsive academic notebook cover. Primary request: create a square seamless fine-pebbled leather texture, photographed perfectly straight-on, covering the entire image edge to edge. Subtle close-grain calfskin, tiny realistic pores, no large creases. Neutral medium gray monochrome, soft uniform diffuse light, low contrast so a CSS course color tint can be applied. No object outline, perspective, vignette, shadows, text, seams, stitching, branding or watermark. All four edges tile seamlessly. The image is a material surface only.

Smooth material prompt:
Use case: product-mockup. Asset type: subtle seamless material tile for academic book covers. Create a square image entirely filled with smooth lightly burnished bookbinding leather, very fine pores and restrained natural irregularity, quiet realistic material detail. Perfectly flat straight-on macro material photograph with neutral medium gray monochrome, low contrast and perfectly even diffuse illumination suitable for a colored CSS overlay. It must tile seamlessly on all four edges. No creases, broad shine, edge, object outline, perspective, stitching, text, logo, watermark, border or vignette.
