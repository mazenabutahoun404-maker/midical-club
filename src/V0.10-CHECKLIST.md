# MedClub V0.10 integration checklist

## Replace and build

- Back up the current `src` directory, then replace it as one unit.
- Keep the existing React, TypeScript, Vite and Tailwind dependencies.
- Run strict TypeScript checking, every V0.2–V0.10 automated test and the production build.
- Confirm the console has no MedClub source exception.

## Admin shell

- Sign out, open `/admin` and confirm sign-in returns safely to admin.
- Sign in with the V0.8 preview account and confirm admin feels separate from public and personal spaces.
- Test expanded/collapsed vertical navigation and horizontal navigation on larger screens.
- Confirm the phone navigation is horizontal, readable and has no visible scrollbar.
- Hover and activate every navigation destination; confirm icon motion is brief and not distracting.

## Overview

- Confirm six operational metrics use the admin service rather than values embedded in JSX.
- Open the scientific queue, stale-content link and activity-history link.
- Confirm the permission boundary is visible and does not imply that team membership grants access.

## Content review

- Search by title, contributor and topic; test every status and type filter.
- Select each record and review contributor, reviewer, rights, references, version and history.
- Request changes and confirm an empty decision note is rejected.
- Approve an under-review item, then publish it as a separate action.
- Confirm draft, already-published and unsafe records cannot take invalid transitions.
- Reload and confirm the device-local preview state persists.

## Activity and versions

- Search activity and filter normal, attention and high-risk operations.
- Confirm actor, role used, date, result, resource and before/after values are visible.
- Confirm there is no edit or delete action for activity records.
- Compare at least two content versions.
- Restore an earlier version and confirm a new current version appears without deleting history.
- Confirm restoration creates a high-risk activity record.

## Responsive, RTL and accessibility

- Test English and Arabic at narrow widths and 200% zoom.
- Complete review, publish and restore flows with keyboard only.
- Confirm focus returns after publish and restore dialogs close.
- Enable reduced motion and confirm ECG drawing, orbiting, scans and displacement stop.
- Verify status remains understandable without relying on color.

## Before production admin

- Replace the local adapter with authenticated server endpoints.
- Enforce capabilities on every server operation; route visibility is not authorization.
- Add founder protection and high-risk approvals in V0.12.
- Store append-only audit records outside ordinary content mutation paths.
- Sanitize secrets, tokens, credentials and private values before logging.
- Define retention, export and incident-alert policies.
