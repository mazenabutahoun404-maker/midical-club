# MedClub V0.13.24 — Study refinements

Replace the entire existing `src/` directory. Existing project configuration and dependencies remain unchanged. All V0.13.23 source files remain in this archive; previous release notes are historical. This release intentionally replaces the old appearance shortcuts and merges Guidance/Books into Notes.

## Book and shelf

Outside focus, the book uses equal small gutters within the reading area below the shelf, including at the bottom. The gutter respects safe-area insets. Header height is 54 px on desktop and 52 px on phones; its border stays at the screen top. Shelf grain is a lightweight local SVG with a wood gradient, bevel and brackets. The existing persistent shelf, course selection, drag/arrow navigation and large catalogue support remain intact.

Focus-mode book dimensions and its 3 px frame are unchanged. Campus navigation remains absent throughout courses. Section flags retain keyboard, touch and manual orientation controls. Guidance and Books no longer appear as tabs; their files and resource reading positions remain accessible under Notes. An active legacy Guidance/Books section migrates to Notes.

## Notes

The Notes section has publisher notes, course files and private notes attached to the current course. Publisher prose supports English and Arabic; editing uses the existing course content-edit/import permission. Its current storage adapter is device-local preview data, **not shared publishing**. Production must enforce permissions and persist publisher text in the content service/API. Private notes remain isolated by the signed-in account on the device.

The notes tool opens to saved cards. The + icon opens a title/body editor with General or Course association. Existing edits autosave after 600 ms; new notes require Save (or leaving a non-empty draft). Save returns to the list and produces a finite receipt. Edit appears on hover/focus and stays accessible on phones. Delete is available from the editor with confirmation. A left swipe reveals Delete; a deliberate full swipe deletes, while vertical gestures remain scrolling. Deletion offers 10 seconds of Undo. Failed deletion restores the card; failed saves preserve the draft for retry/download. At the 500-note limit a new save is rejected rather than discarding an older note. Lists reveal 20 items at a time with search and Show more.

## Timers and movable tools

Focus and Relaxation timers share Start/Pause/Reset controls. Session duration is 1–180 minutes; rest is 0–60 minutes. Finishing a session prepares a **paused** rest period, which the student starts when ready. Finishing rest returns to the configured session. No rest period begins unseen.

Setup, start, pause, reset and completion receive short visual/status feedback. A docked handle receives a finite completion pulse and small indicator; the hidden bar never shows a countdown or opens itself. Visible timer badges remain available. The dock still recovers by hover, tap or keyboard and can be moved from its handle. Handle hover/focus uses readable semantic colors in all light/dark palettes. Reduced motion and forced-color modes retain static status feedback.

## Appearance and PDF controls

There is one Appearance chooser in navigation and course controls. The separate light/dark/system cycle button is removed from all live headers. Choices are grouped into six Light themes, six Dark themes and System. Selecting a theme sets its palette and mode together. System follows the device using MedClub colors. Earlier stored preferences and cross-tab synchronization remain compatible; the unused legacy mode component remains solely for migration compatibility.

A theme hover or keyboard focus reveals four lightweight SVG views: Home, Courses, Study reader and Workspace. These are **illustrative layouts using the actual palette tokens**, not screenshots of the live website. Auto playback advances every 2 seconds; selecting a view or theme pauses it. Closing and reopening resets automatic playback. Reduced motion makes it static; hidden browser tabs pause it. On phones, tap a theme and use the view buttons. No generated raster images or animation package is needed.

PDF paper follows both light and dark palettes. Page colors still allows Original colors, and a site appearance change returns the PDF to automatic theme paper. Recoloring affects displayed neutral pixels only, not PDF bytes or cached source rasters; Original colors remains useful when inspecting image detail. Raster memory limits and route-split PDF rendering are retained.

The filename/external/close row is thinner outside focus (32 px for fine-pointer desktop, 44 px touch targets). Focus PDFs always have Close in their own PDF control row; missing URLs and non-PDF readers retain a fallback close control. PDF page buttons, page edges and keyboard turns stop at the file boundaries. They never change course sections. Section turns return after leaving the PDF.
