# MedClub V0.13.23 — Reading frame and palettes

Replace the entire existing `src/` directory with this complete tree. Existing project dependencies and configuration remain unchanged. The archive retains all V0.1–V0.13.22 source files, including the PDF importer, study-position storage, persistent bookshelf, notes, GPA tool and permission model.

## Reading space

- Courses lock only the outer document scrollbar. The PDF viewport retains wheel, touch and keyboard scrolling; its scrollbar is visually hidden. Leaving a course releases the document lock.
- Focus mode uses the book frame at the viewport boundary, with 3 px inner framing and no reserved toolbar footer. Section flags overlay the edge instead of resizing the reader. Hover, focus and touch reveal them. Horizontal flags retain separate space for PDF controls, and phone targets remain 44 px.
- The shelf/header is 60 px on desktop and 56 px on phones, reduced from 76 px. Its SVG shoulders now contain the utility buttons at those heights. Below 1201 px, controls use the existing compact panel.
- Shelf book edges are more visible, while the same mounted shelf and its scroll position survive course switching.

## PDF colors

The site appearance automatically controls PDF paper. Entering dark mode remaps neutral white paper to the selected dark surface and neutral black ink to a light reading color. The existing PDF tools include **Page colors**, which independently restores **Original colors** or uses dark paper. Changing site mode or palette resumes automatic paper colors.

This operates on the displayed canvas only. PDF bytes, downloaded files and cached original page rasters remain unchanged. Strongly colored pixels are preserved; neutral pixels inside grayscale photos and diagrams also remap. Choose **Original colors** when inspecting image detail. This is a display preference, not a fidelity-preserving medical-image viewer.

Recoloring runs only when a page is rendered or its palette changes, using a bounded color lookup cache. Existing raster limits remain 1.2 million pixels per page on phones and 2 million on larger screens. No new rendering or animation dependency was added.

## Tools and files

- A deliberate move within 5 px of any viewport edge docks the tools at that edge. The recovery tab is attached to the physical edge. Tap, hover, keyboard reveal, dragging, timer status and saved positions remain available.
- Delete remains permission-aware and only applies to removable local PDFs. A small PDF badge fills its quiet slot; Delete replaces that badge on hover/focus, without shifting the other actions. Touch users receive a visible delete target.
- Import progress, completion reset, review/favorite controls on closed file cards, and deletion failure recovery remain intact.

## Appearance

Open **Appearance** in normal navigation, or **Reading palettes** in the course controls. Choices are:

| Palette | Intended character | Initial mode when selected |
| --- | --- | --- |
| MedClub | Original wine and warm paper | Keeps current mode |
| Paper | Warm ivory and restrained ink | Light |
| Dusk | Quiet slate with wine accents | Dark |
| High contrast | Strong text and clearer boundaries | Keeps current mode |
| Tokyo Night | Muted blue/violet, with a day counterpart | Dark |
| Solarized | Deep teal at night and ivory by day | Dark |

Every palette works with the existing direct light → dark → system cycle. Preferences persist on the device, synchronize across tabs and migrate earlier preferences without losing navigation settings. Native labeled radio controls, Arabic text and system forced-color overrides remain available. High contrast is a palette name, not a claim that the whole application has been certified accessible.

Tokyo Night and Solarized are adapted color inspirations, preserving MedClub's wine action color and readable label contrast. No external theme code or package is incorporated. References: [Tokyo Night](https://github.com/folke/tokyonight.nvim), [Solarized](https://ethanschoonover.com/solarized/).

For ordinary student reading, start with Paper during the day or Dusk/Solarized at night. Tokyo Night offers a more colorful alternative without neon animation.
