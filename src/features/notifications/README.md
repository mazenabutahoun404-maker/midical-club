# Notifications — V0.3

Implemented at /my/notifications: course updates, derived saved-plan reminders, all/read/unread filters, bulk mark-read, resource/page actions and header unread counts.

The mock registry provides notifications.list; the workspace service persists readNotificationIds. The demo reminder horizon is fourteen days from the configured demo date. These are in-app records, not push, email or operating-system notifications.
