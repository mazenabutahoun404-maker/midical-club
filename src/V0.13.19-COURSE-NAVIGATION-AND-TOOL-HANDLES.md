# MedClub V0.13.19 — Course navigation and tool handles

Based on the complete V0.13.18 source. The recent book, paper-flag, shelf,
hero, typography and color designs remain included.

## Behavior

- Entering a public or personal course hides campus navigation immediately,
  including when it was pinned elsewhere. Scrolling does not reveal it.
  Outside Study focus, the existing edge lets users deliberately reopen it.
  Pinning it inside the course keeps it open until the next course. Study focus
  still removes both the menu and its reveal area.
- The reading desk uses the full available width again. Automatic section
  layout uses side paper flags while campus navigation is hidden, horizontal
  flags when it is deliberately revealed, and side flags in Study focus.
  A student's saved manual orientation continues to take precedence.
- A stronger paper tab with six grip dots identifies a docked toolbar. Hover,
  click or keyboard focus opens it in its saved position. The edge tab itself
  can be dragged, as can the existing upper grip. Pointer capture remains alive
  while dragging; release within 24px of any edge docks and tucks the toolbar.
  A drag does not trigger an accidental click. Cancelling restores the original
  position. Arrow keys move the tools; Home on the grip resets their position.
- An open tool panel stays available. Running timers remain visible on the
  docked handle. Tucked controls are inert and do not block document interaction.
- Learn directly opens `/learn`, the same catalogue as Explore every course.
  A separate static chevron preserves the learning-category menu on expanded
  desktop navigation. Arrow Down opens categories and Escape returns focus to
  Learn. Phone navigation retains its direct Learn link.
- Course PDFs, authorized importing, personal notes, GPA, reading-position
  restoration, existing account permissions and previous routes are retained.
  PDF importing remains in authorized course sections, outside the tools panel.
