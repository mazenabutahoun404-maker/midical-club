# MedClub V0.13.25 — Study desk and action feedback

Replace the entire existing `src/` directory. Keep the existing project configuration and dependencies, including the Tailwind 4 PostCSS integration. V0.13.24 is the exact baseline; earlier release notes remain historical. Focus book dimensions, course navigation rules, shelf persistence, PDF page boundaries and all existing source files are retained.

## PDF zoom and page movement

The PDF spread sits in a canvas with a physical left-to-right scroll origin, while the pages retain the chosen language direction. Enlarged pages can be panned horizontally with touch, a trackpad, a scrollbar gesture, or the labelled Pan slider. The slider supports keyboard input, appears only when the spread exceeds the reader width, and reserves bottom padding so it does not cover the last line. Panning clamps when the viewport shrinks or zoom changes. PDF page navigation still stops at the first/last page and never changes course sections.

Page movement now uses a narrow paper ribbon: the outgoing face peels away and reveals actual incoming content beneath it. A small highlight and three paper flecks travel along the fold. The effect stays inside the spread, mirrors in RTL and has no rotating text or full-screen curling sheet. Click section transitions use the same paper-peel language. Reduced motion removes the decorative layers. The existing page cache, preview rendering and selection layer remain intact.

## Study tools

The public Study Tools page opens with the timer in its hero. Timer, Notes and GPA selectors below replace the tool in that same space. Opened tools stay mounted so switching tools preserves drafts and timer state. Signed-out users can use the timer; private Notes and saved GPA access retain their account checks.

Public and course timers use the same controls and state helpers: Focus, Relaxation, editable session/rest durations, Start/Pause and Reset. A finished session prepares a **paused** rest period; no rest starts unseen. The public timer persists by account on the device, checks elapsed wall time after backgrounding, and pauses its one-second UI interval while the document is hidden. Course timer completion/docked-handle behavior is unchanged.

The timer has a round alarm-clock face, two bells, feet, twelve ticks and a measured hand/ring. Notes have a notebook binding and layered paper edge. These are CSS/SVG surfaces around real accessible controls, with no new 3D renderer or continuous decorative animation. Course tools inherit the current book cover and paper colors. Both the movable grip and edge recovery handle now match the cover; forced colors retain system colors.

## Undo and deletion feedback

Deleting a PDF or private note sends a labelled paper card along a short arc into a visible bin. Cart items, calendar entries, library collections, private contribution drafts, assessment records and builder blocks use that same finite flight. The source stays in place until the flight finishes; data changes are reported only after the mutation succeeds. Repeated PDF/cart deletion is guarded. Reduced motion and unavailable animation APIs proceed immediately with static receipts.

Undo is available on desktop and phones:

| Editable record | Recovery |
| --- | --- |
| Local PDF | Same ID, actual Blob, filename and metadata; fresh viewer URL |
| Private note | Deleted note or the original title/body/course association before an edit |
| Publisher notes | Previous English/Arabic prose |
| Library | Deleted collection, renamed collection, collection membership, removed saved item with its timestamp |
| Calendar | Deleted/edited study entry, including its notes |
| Cart | Removed line or previous quantity |
| Profile | Original editable fields, including both localized strings in the local adapter |
| Private contribution | Deleted/edited draft with its original ID and history |
| Recruitment | Previous editable application draft |
| GPA calculator | Twenty-step account-scoped Undo/Redo for input edits and course-row deletion |
| Academic insights | Deleted assessment attempt or previous/absent confidence rating |
| Page builder | Existing Undo/Redo history; block deletion gains the flight |

GPA Undo/Redo keeps twenty steps while the calculator is open; builder history retains its existing behavior. Global receipts offer 15 seconds of Undo; private note deletion keeps its existing 10-second recovery and note edits offer 15 seconds. Editing notes groups changes from opening the editor through its autosaves into one original before-image. Most reversals compare the affected record to its post-action value, preserving unrelated work and rejecting newer edits. Account changes prevent cross-account Undo, and PDF changes recheck current content-edit permission. A failed recovery keeps a retry action while it remains available. Expired global receipts are dismissed and release their before-image. Governance approvals, publishing, submission, reservations and other committed workflows retain their established rules.

PDFs remain device-local. Blocked storage keeps an explicitly session-only copy. Removing a durable PDF waits for IndexedDB success; an abort preserves the card and file. Undo restores the actual Blob, with the same storage fallback. Shared storage, server authorization and record-version checks are production responsibilities. Optional adapter methods `auth.restoreProfile`, `contributions.restoreDraft`, `insights.restoreAssessment` and `insights.restoreConfidence` are implemented by the local preview; API adapters should implement equivalent authenticated/version-checked operations. Legacy profile adapters can restore the previously displayed input values.

## Covers and appearance

Three new generated textures supplement the existing two: crosshatched Saffiano, brushed suede and diamond embossing. Stable course-ID selection keeps the material consistent on its catalogue cover, shelf book and notebook. Neutral texture layers preserve the course's established cover colors and never overlay PDF content. The new WebP textures are 512 × 512 and add 152,604 bytes in total; the original leather assets remain unchanged.

Appearance retains six Light themes, six Dark themes and System, now in a compact multi-column preset grid. Every preset has a three-color swatch. Desktop uses a side preview; phones place it above the presets. Four illustrative SVG views use actual theme tokens. Playback advances every two seconds, pauses on manual selection, resets after closing/reopening, pauses in hidden tabs and stays static under reduced motion. These are palette/layout previews, not screenshots of the live site.
