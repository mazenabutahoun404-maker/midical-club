# MedClub V0.13.31 — Navigation polish

This release builds on the accepted V0.13.30 appearance update. Replace the complete `src/` folder, retaining your existing project configuration and dependencies. No dependency was added.

## Changes

- Public and personal headers share the same Search → Notifications → Language → Profile order. Public Appearance stays before these controls; personal Appearance stays in its navigation and phone More menu. Anonymous public headers retain their sign-in entry and omit account notifications.
- A shared header profile portal shows an avatar/initials, profile label and name where space permits. Narrow layouts retain a named 44px profile target. The existing public `/my`, personal `/my/profile` and sign-in return paths are preserved.
- The personal sidebar's duplicate profile/avatar/footer is removed. Its permission-gated Admin Control Room portal occupies that bottom area, with aligned icon, flexible title and directional arrow. Mobile More retains the same permission check and portal.
- Profile portals use the selected palette's accent surface. Admin Control Room uses a separate quiet blue/violet treatment with a clear boundary and a brief hover response. High-contrast mode retains its own semantic colors.
- Public, personal and admin sidebars gain two shallow offset layers with a light shadow. RTL reverses their horizontal offset, horizontal navigation uses downward layers, and high-contrast/system-color modes avoid decorative depth.
- Pin/hide icons are 15px, with compact 30px visible surfaces. Pointer controls use 32px targets; touch and hybrid-device controls use 44px targets. Dedicated control slots prevent overlap with Appearance and links; collapsed rails stack the controls.
- Overflow cues are shorter, weaker and derived from the selected theme. Vertical fades use 14px strips; horizontal fades use 14px edges with the correct RTL direction. OS forced colors use thin explicit boundaries.
- Header actions retain usable targets down to 320px. Narrow headers compact profile/brand text, truncate location text where appropriate, and remove the decorative admin live chip when it competes with controls. The personal Appearance label compacts where the sidebar is narrow.
- Focus outlines use the palette's readable ring token. New transitions respect reduced motion. Existing navigation folding, icon morphs, route transitions and reader behavior remain feature-owned.
