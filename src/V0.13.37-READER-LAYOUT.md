# MedClub V0.13.37 — Turn controls, tooltips and course header leather

This complete source folder builds on V0.13.36 and contains the three requested reader fixes.

## Changes

- Section-turn buttons now sit in an in-flow footer outside the scrolling section content. Their new classes do not inherit the full-height PDF edge overlays. File cards, delete actions and close controls retain their own hit areas. Repeated section turns are disabled while a turn is active.
- PDF-turn buttons occupy separate 44px grid columns, with 8px gaps around the document. Readers narrower than 520px use a separate footer with 72 × 64px buttons. Horizontal pan controls have a separate row. PDF page geometry uses the actual viewport width after accounting for these spaces.
- PDF tool buttons retain the custom Radix tooltip and its arrow. Native `title` attributes are removed; accessible labels, click handlers and disabled behavior are preserved.
- The course header has an explicit, visible leather layer using the same stable course material as the notebook and shelf cover. The existing header shape remains, with the texture below the controls and caption. A subtle dark glaze keeps the text readable.

The V0.13.36 PDF document/raster cache, paper worker, text-selection stream and page-turn motion are preserved. Theme definitions, personal/course notes, existing save animation and homepage files remain byte-identical to V0.13.36.

## Integration

Back up and replace the existing `src` with this entire folder. Keep the project configuration and dependencies. No package dependency is added.

## Verification

- Full strict TypeScript checking and production Vite build passed in the existing source verification project. The build reports existing large JavaScript chunks.
- React DOM interaction checks passed at reader widths 320, 640 and 900px in LTR, and 1024px in RTL, using a mocked DOM and PDF engine. Zoom, search and bookmark actions did not reopen or rerasterize the PDF; file changes and close released the previous document.
- Actual Radix tooltip rendering passed in jsdom: hover displays one custom tooltip with its arrow, native button titles are absent, and click/disabled behavior is preserved.
- CSS cascade checks passed for seven widths from 320 to 1600px, LTR/RTL and horizontal panning, including older course CSS loaded after the new layout rules.
- All eight leather assets and four course-cover colors passed caption contrast calculations. The minimum ratio was 6.15:1 for the new material-layer blend.
- Archive comparison confirms that changes are limited to the requested reader/header components, their stylesheet import, version metadata and this release note.

No live browser geometry or device timing measurements were available. The DOM/cascade checks and pixel calculations are not substitutes for checking the integrated site on desktop and phone browsers.

The homepage redesign is a separate design decision for the next update.
