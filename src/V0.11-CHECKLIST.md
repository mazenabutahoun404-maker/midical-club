# MedClub V0.11 integration checklist

## Access and preservation

- Replace the existing `src` directory as one unit.
- Sign in, open `/admin` and confirm the V0.10 dashboard still loads.
- Open `/admin/content`, `/admin/activity` and `/admin/versions` and run one applicable workflow in each.
- Open `/admin/builder` from the same admin navigation.

## Page library

- Filter all, draft, scheduled and published pages.
- Search by localized title and path.
- Create a page with English and Arabic titles and a valid `/path`.
- Duplicate a page and confirm the copy opens as a draft with unique block IDs.

## Editor

- Add every standard block type.
- Reorder blocks by pointer drag and by the up and down buttons.
- Duplicate, hide and delete blocks.
- Edit English and Arabic headings, body and actions.
- Change audience, language visibility and block timing.
- Edit page path, page audience, visual theme and SEO fields.
- Save a block as reusable and insert it again from the palette.
- Select a small local image and confirm its preview; reject files over 1.5 MB.

## State and publishing

- Confirm autosave reaches Saved after a canvas change.
- Test Ctrl/Cmd+S, undo and redo.
- Preview desktop, tablet and phone widths before publishing.
- Publish and confirm a milestone version appears.
- Schedule a page and confirm the start time is required.
- Restore a previous milestone and confirm it becomes a new draft revision.
- Reload and confirm device-local state persists.

## Responsive, RTL and accessibility

- Test the library and editor on phone, tablet and wide desktop.
- Complete the editor workflow using keyboard controls.
- Test English and Arabic RTL.
- Test 200% zoom and reduced motion.
- Confirm hidden or targeted blocks are identifiable without relying on color.
- Confirm all native dialogs move focus safely and close with Escape.

## Before production CMS

- Replace `BuilderService` with authenticated server endpoints.
- Add server document schemas and sanitize rich content.
- Use object storage, scanning, quotas and durable asset references.
- Enforce page and block visibility and schedules on the server.
- Publish atomically and invalidate caches only after success.
- Connect page actions to immutable audit history.
- Enforce V0.12 capabilities and founder protection before exposing admin in production.
