# MedClub V0.13.42 — reader scale and campus restoration

This is the complete updated `src` folder, based on V0.13.41. Replace the existing source folder and keep the project's existing dependencies and configuration. No dependency was added. All previous files, courses, dashboards, themes, data and save-flight behavior remain included.

## Requested changes

- Removed the custom PDF Pan slider and its reserved row. The PDF has thin native course-colored scrollbars, normal touch scrolling and mouse grab panning. Drag blank paper normally; hold Space while the reader is focused, or use the middle mouse button, to drag over text. Ordinary dragging over text still selects it. Controls and note markers retain their own interactions.
- PDF 100% now means the first PDF page's natural width at 96 CSS pixels per inch (PDF scale 96/72), rather than a width fitted to the reader and mislabeled 100%. A4 is about 794 CSS pixels wide. The separate Fit control fits the document into the reader, caps enlargement at 100%, and shows the actual percentage. Phone and companion readers initially fit. The supported zoom range is 25–175%.
- Raster width stays stable through zoom, Fit, window resizing and switching single/spread layouts. Those controls continue to use the existing document and prepared raster cache. Page size metadata comes from the already-open document. Existing taller, separate page-turn controls and one-page preference remain intact.
- Removed raster pointer movement from the home hero. Path effects animate separately from the sharp stationary photograph. Reduced the large glow wash. Authentication now always uses the 1672 × 941 artwork, including on phones.
- Generated five intermediate restoration images in daylight and five at night. Name, email, batch, year, password and confirmation correspond to Learning, Media, Community, Mentorship, Contribution and Journals. Valid completed fields reveal a path; after the path arrives, their building is repaired and illuminated. Invalidating a field withdraws that repair. Editing earlier fields and filling fields out of order remain supported.
- Normal desktop progress uses complete generated frames, avoiding cutout seams. Out-of-order progress and the phone composition use per-building patches. The sixth stage uses the existing fully restored photograph. Reaching the valid Create button speeds the remaining path sequence; verification shows the restored campus. Reduced-motion users still get the repaired buildings.
- The photograph, restoration layer and path/label overlay share one transformation. Arabic mirrors the scene; only text is counter-mirrored. Labels stay anchored to their walls. The entire scene fades at the edges into the page background, including in dark mode.
- Signed-out Appearance offers only MedClub Light and MedClub Dark. The full theme library and workspace controls open after registration or login, including the verification stage. Guest mode is stored separately, so signing out preserves the account's saved palette. New registration starts in the selected guest mode.

## Integration

1. Back up your existing `src` folder.
2. Extract this archive and replace that folder with its complete `src`.
3. Retain your Vite, React, TypeScript, Tailwind and PDF dependencies/configuration.
4. Run your project's type check and production build, then open registration and a course PDF.

This remains the existing frontend project. Its local authentication/demo services and deployment boundaries are unchanged; see the existing architecture and integration documents.

## Artwork

Assets: `src/assets/home/auth-renewal-day-{1..5}.webp` and `src/assets/home/auth-renewal-night-{1..5}.webp`. Each is 1672 × 941, encoded at WebP quality 96 without resizing. The original active/awaiting artwork is retained.

Built-in image generation was used, with the matching awaiting image as the edit target and active image as the restoration reference. The shared prompt specified: precise object edit; preserve the original composition, scale, camera, framing, six building coordinates, central empty plaza, sharp textures and image edges; keep warm ivory daylight or navy night ground; no text, captions, collage, border or UI; repair only the listed buildings to the clean occupied illuminated reference; leave every remaining building abandoned; remove damage, excess vines and dirt just on repaired buildings, activate realistic warm interior lights, and clean their surrounding paths; return one crisp full-frame landscape image without haze or blur.
