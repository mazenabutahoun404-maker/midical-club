# MedClub V0.13.26 — Navigation and leather covers

This update extends the complete V0.13.25 source. Replace your existing `src/` directory with this whole tree; retain your project configuration and existing dependencies.

## What changed

- Reserved a 44 px logical page-turn hit strip beside vertical section flags. The unfocused file reader reserves 64 px for its inset. Expanded flags and previews remain outside that strip, mirrored in Arabic. Previous and next controls have 44 px targets; the PDF canvas and focus frame are preserved.
- Raised leather-grain visibility from 18% to 72%; the shelf uses 78%. The texture fills each cover, with restrained relief around its edges. Cover titles, course code, metadata and actions remain real readable HTML above the material layer.
- Added three generated textures: woven leather, ostrich-style grain and sculpted fluted leather. Eight materials now share a deterministic assignment across catalogue, shelf and opened book; all eight are used by actual sample courses.
- Reduced personal sidebar destinations from 16 to 12. **My activities** groups Events, Opportunities and Contributions; their existing routes and workflows remain intact. Its local icons are distinct and static. Four core mobile destinations are unchanged, with My activities in More.
- Profile opens from the personal header icon and sidebar avatar. Settings remains a sidebar destination. Notifications remain in the personal header and now also appear in the public header for authenticated accounts.
- Both notification shortcuts use the same unread state and shared request. Notification queries are scoped to the current account. Signed-out public visitors do not mount the notification shortcut or request notification data. The badge is capped visually at 99+, while its accessible label gives the full count.

## Source and integration boundaries

All 717 V0.13.25 files are retained. Profile, notifications, events, opportunities, contributions, recruitment, mentorship and existing course routes are preserved. The new `/my/activities` entry opens `/my/events`; the three local tabs retain their established URLs. It remains protected by the existing authentication route.

No runtime dependency was added. Texture assets use optimized 512 × 512 WebP; existing course colors and appearance themes remain in control of the covers.

This is a complete source deliverable, not a production deployment. The existing device-local preview services remain in use. The new notification shortcut does not add server push or a new messaging backend.

## Proposed next features

These are proposals, not features implemented in this release. They extend the existing notes, timer, course, calendar, activity and governance systems. Connected Learning Materials remains excluded.

| Feature | Concrete student value | Main work required |
| --- | --- | --- |
| PDF margin notes | Attach a private note or highlight to a specific passage; open directly at that page later. | PDF text/rectangle anchors, source-version handling, private note storage and cross-device sync. |
| Recall desk | Turn student-authored highlights into question cards, schedule short spaced reviews, and retain source-page references. | Review scheduling, answer feedback, accessible question formats; no unreviewed generated medical answer presented as fact. |
| Exam sprint planner | Work backwards from real exam dates and available hours; reorganize study blocks after missed sessions. | Student-supplied deadlines, editable workload assumptions, calendar integration and conflict checks. |
| Case journeys | Work through tutor-reviewed cases as clues appear, explain reasoning, then compare with an authored explanation. | Reviewed case authoring and versioning, teaching rubrics and assessment history. |
| Offline course packs | Download selected PDFs and notes with visible size and freshness; continue studying without a connection. | Service worker/cache strategy, storage limits, per-account access, file revisions and reconnection conflict handling. |
| Verified campus portfolio | Collect confirmed event attendance, publications and contributions into a selectively shareable portfolio. | Verifier permissions, evidence records, revocation, privacy controls and export. |
| Quiet study rooms | An invited group shares a timer and goals; personal notes remain private. | Durable rooms, presence, consent, low-bandwidth updates and abuse controls. |
| Living campus progress | A private campus or notebook gains small visible improvements after recorded study milestones and verified contributions. | Real evidence-backed milestones and a calm-mode alternative; no public exposure of private study activity. |

My recommended first pair is PDF margin notes plus the recall desk: it connects the present study environment to actions students can return to.
