# MedClub V0.13.47 — exam studio, recall queue and visual repairs

This is the complete `src` folder, based on V0.13.46. Replace the existing `src` directory and keep the current project configuration and dependencies. Every previous source file is retained. No package dependency was added, and exam APIs remain disconnected.

## Repaired recall editor

The card editor opens in a native dialog portaled outside `.study-hub`. Its previous fields depended on styles scoped to that ancestor, leaving the portaled controls almost invisible and laid out inline. The editor now has its own complete local styling: separate labels, full-width course/question/answer controls, visible borders, readable foreground/background colors, generous field heights and keyboard focus outlines. Textareas use automatic text direction for English and Arabic content. Creation, editing, native validation and the existing save contract are retained.

## Correct Arabic course books

Arabic volumes now have the spine on the physical right, the paper edge on the left, and a right-hand cover hinge. The spine position, paper-edge rounding and depth shadows are mirrored together. The existing cover still opens from its free left edge. English books retain their left-hand binding. Titles, cover materials, course colors and reader behavior are unchanged.

## A dedicated exam environment

Active Practice, Self test and course Recall sessions now use a full-width learning shell. The site header, sidebar, mobile navigation and footer are not mounted. Results, setup, history and browsing return to the ordinary MedClub workspace. The standalone personal recall desk uses the focused shell too, with its own exit to the study desk.

The active question screen has one central question area and a compact sticky session bar. Saving/exiting, Notes and Appearance remain directly available. The question map is opened on demand, replacing the permanently displayed side map. Reading preferences are a small disclosure; finishing is available without reaching the last question. A short progress row and save state remain visible. Large marketing headings and duplicate session instructions were removed from active study.

The question, choices, optional confidence, confirmation and next/previous actions form a single reading order. The existing answer-confirmation logic, immutable practice answers, editable self-test answers, flags, bookmarks, reports, explanations, keyboard navigation, recovery drafts and ordered saving remain intact. The timer continues to update separately from question rendering.

## A queue of actual recall cards

The stack now renders up to three real upcoming questions behind the two-sided active card. Each sheet has its own question ID and prompt; there are no invented upcoming cards when the queue has fewer items. The stack mirrors its fan direction in Arabic.

After a successful rating changes the active question, the reviewed card's visible face leaves the front and the next sheet advances. The animation uses the previous card's actual question/answer and only runs on a card change. The answer remains an explicit tap/keyboard reveal, with no typing or answer selection during recall. Upcoming sheets do not reveal their answers.

Personal recall separates Review and My cards, keeping collection management out of the main review area. Card creation/editing and PDF source links remain available. Course recall retains private device-local round progress; personal recall retains the existing scheduling service. Neither self-rating changes an exam score. Reduced motion switches sides and advances without the turn/departure animation.

The design uses existing MedClub colors and brand artwork plus CSS paper geometry, depth and finite transitions. No generated artwork, animation engine, WebGL dependency or continuous rendering loop was introduced.
