# MedClub V0.13.15 — Study refinements

Replace the existing `src/` directory with this complete tree. It retains all V0.1–V0.13.14 modules, routes, assets, theme tokens and access rules; no new runtime dependency is required.

## Reading and study tools

- PDF pages fit the available reading width instead of shrinking to the available height. Two pages remain on wide screens, one on phones and companion readers. Zoom and native document scrolling remain available outside Study focus.
- The compact labelled tool strip moves by dragging its half-width upper grip. Only the grip captures pointer gestures. Arrow keys move it, Shift increases the step, and Home or double-click restores its default position. Position is saved per account and course and clamped when the viewport changes. Pointer updates use one animation frame; the drawer follows the strip and stays on screen.
- A started or paused timer remains visible above its icon after closing the drawer. Near the top of the viewport it appears below the icon. The absolute-time countdown recomputes on visibility changes and does not poll a hidden document.
- Previous/next controls span the full vertical reading edges. The actual PDF viewport scrolls independently of these stationary controls. Vertical touch movement still pans the document; a tap turns a page. No page dragging was restored.
- Section flags have themed paper, a folded edge and a binding shadow. Hover or keyboard focus extends their width to reveal their title and first-material glimpse, with the existing attached preview. Flags retain their vertical positions; RTL mechanics mirror correctly.

## Curriculum shelf

Outside Study focus, the course toolbar becomes a shallow shelf with tucked themed books and small labelled utility controls. It uses the current batch term containing the course or its clinical-year membership, falling back to the same year and track when curriculum records are unavailable. Real curriculum membership may include a shared course from another study year.

Only the lower part of each book is visible initially. Hover/focus slides out roughly half its cover. The visible strip has a larger transparent hit area for touch and a small course-name label on devices without hover. Clicking opens the existing public/personal course route with the established course-opening transition and restores that course's selected file, PDF page and reading position. The whole shelf is absent in Study focus; no campus header or reveal button is added there.

Phone controls use two compact rows at the shelf edge; the duplicate Tools header button is omitted because the labelled tool strip stays available. The small campus hint sits at the screen edge rather than covering the tools.

## PDF import

The temporary personal PDF testing picker is removed from the course interface. To attach actual course material:

1. Sign in using an account with `content.review`, `content.publish` or `builder.manage`.
2. Select the target material section and choose/drop PDFs on its importer, or open **PDF** in the tool strip. Overview, recordings and external-link sections send imports to Notes.
3. The importer reacts to a file entering the drop zone. After release it shows each filename and size, validation/storage status, real completed-file counts and a success check. The drawer's **Read PDF** action opens the imported document after the visible receipt.

Both the importer and local repository validate the PDF signature, type, nonempty content, 30 MB per-file limit and eight-file batch limit. Overlapping submissions are blocked. Progress counts completed writes; it does not simulate a network upload. IndexedDB success is reported after transaction completion. When device storage is unavailable, the memory fallback is labelled **session only**.

Guests see sign-in guidance, and signed-in accounts without the required capabilities see an access explanation. Import and removal callbacks also guard the current capability result. These preview permissions do not replace server enforcement. PDFs remain device-local and are not published to other students; shared storage still requires the course API.

The earlier temporary-file helper remains unused in the source tree for release continuity. It is not imported by the course route or exposed as a product tool. No test PDFs are included in this source package.

## Hero artwork and motion

The generated tab artwork stays part of each hero background. Copy-area blur is reduced from 9 px to 3 px, with lighter, localised tinting so more of the image remains visible. Copy uses the existing foreground ink token for readability; recruitment fact contrast and the theme palette are retained.

The established Save-to-Library motion, PDF landing/check animation, realistic page surfaces and course entrance remain connected. New shelf, grip and receipt motion have reduced-motion alternatives. No decorative loop or extra animation library was added.
