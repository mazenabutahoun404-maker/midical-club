# MedClub V0.13.33 — requested workspace colors and glass

This complete `src` release builds on V0.13.32 and changes the four requested areas.

## Bell interaction

The shared notification bell now runs an explicit, single movement on pointer hover
and a slightly larger movement on click, including touch and keyboard activation.
Keyboard focus also receives the small movement. Repeated interactions restart the
animation. New notification arrivals retain their existing small movement and
first-load/account-change handling. Reduced-motion preferences disable movement.
The notification popover and read-status behavior are unchanged.

## Dashboard identity

Personal navigation and headers stay brown; admin navigation and headers stay wine.
Each of the nine palettes has coordinated light/dark versions of those surfaces,
selected states, and visible control boundaries. Page content retains the selected
theme's background, cards and text. Public navigation retains its own palette.
Phone navigation uses the same workspace identity. The compact controls, shallow
navigation depth, weak overflow cues and existing portal layout remain intact.

## Light theme details

Eight light palettes now have distinct tinted page washes and thin curved contours,
plus quiet curves and highlights in the navigation/header surfaces. The accents use
static CSS backgrounds and do not alter geometry, scrolling, content or hit areas.
Study page backgrounds and original media remain free of these page decorations.
The High Contrast palette and increased-contrast preference omit decorative layers.

## Appearance glass

The Appearance dialog has a translucent surface, reflective edge and localized glass
filter. The page outside the panel has no backdrop dimming or blur. Choosing a theme
continues to apply it immediately, so its effect remains visible behind the panel.
Control surfaces protect label contrast; selected choices and keyboard focus remain
clear. When opened from a phone's More menu, the underlying menu and its backdrop
are temporarily hidden and return when Appearance closes. Native dialog focus,
Escape/outside dismissal, background inertness and existing responsive layout remain.
High Contrast, increased-contrast/reduced-transparency preferences, and browsers
without glass support use solid panel surfaces.

## Preserved motion

The save icons flying toward the profile library remain byte-for-byte unchanged,
including `SaveButton.tsx` and the original flight styles. Study progress, the brief
theme color fade and the bookmark fold response from V0.13.32 remain included.

## Integration and verification

Back up and replace the existing project's entire `src` folder with this one. Keep
the existing project configuration and dependencies; this release adds none.

Verification covers executable notification/motion helper checks, all 18 semantic
palette variants, workspace/transparent-control contrast calculations, source
preservation, relative imports in the edited component, and archive integrity.
The 41 helper checks passed. The 270 semantic and 464 additional surface color
pairs passed their contrast thresholds (text at least 4.5:1, controls at least 3:1).
These are source/color calculations, not measurements of every rendered element.
The full project configuration/dependencies and a browser are not included in this
source handoff. A full TypeScript check, production build and rendered device/RTL/
keyboard acceptance test could not be run here and should be run in the host project.
