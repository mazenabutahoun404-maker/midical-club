# V0.2 academic design

## Direction

V0.2 treats academic navigation as a journey, not a conventional card catalogue. The visual idea changes with the task:

| Area              | Visual metaphor        | Interaction                                                    |
| ----------------- | ---------------------- | -------------------------------------------------------------- |
| Learn gateway     | Two connected worlds   | Pointer-following light and layered orbit                      |
| Basic Sciences    | Batch passport         | Progress seal, current-term stamp and lift/reveal hover        |
| Clinical Sciences | Connected path         | Oversized year numerals, changing dark surfaces and pulse line |
| Batch home        | Academic identity card | Current/archive switch and native expandable archive terms     |
| Clinical year     | Year chapter           | Current-focus glass panel and ordered focus strip              |
| Course            | Course atlas           | Section rail, central material stage and compact context card  |

Course accents are configuration-driven: red, russet, olive and purple records set the course atlas highlight, soft background light and active section. This preserves a coherent MedClub system while letting courses feel distinct.

## Motion rules

- Page entry: 320 ms fade/settle with a 550 ms line trace.
- Cards: short lift and small directional-arrow movement.
- Portal light: follows pointer position without moving content.
- Decorative course orbit: slow 24-second rotation.
- No scroll hijacking, delayed content, cursor replacement or full-page WebGL.
- `prefers-reduced-motion` removes orbit/pulse animation and hover transforms. Framer Motion entry transitions also resolve immediately.

## Responsive behavior

At wide widths, the course atlas uses a section rail, content stage and context card. Below 1200 px the context card becomes a horizontal row. Below 960 px the section rail becomes horizontally scrollable and all journey card grids become single-column. Below 768 px, academic navigation remains touch-friendly above the existing bottom dock and dense metadata stacks vertically.

The interface supports English and Arabic. Directional motion and arrows mirror in RTL; the desktop sidebar remains on the left by the user's design decision.

## Honest preview behavior

Material cards describe their format and audience. They can be saved and inspected, but no sample file opens because the fixture URLs are intentionally null. Batch progress values, course assignments and dates are static examples and must be replaced by approved data.
