# MedClub V0.12

V0.12 adds the first governance and access-control product layer while preserving V0.1–V0.11.

## Included

- capability-based roles and route gates;
- five protected founder accounts and an immutable Founder role;
- high-risk access requests with two-person approval;
- user inspector separating roles, team memberships and symbolic titles;
- editable capability matrix for non-protected roles;
- governance overview and approval queue;
- prioritized Admin portal in My MedClub;
- grouped Admin navigation with a compact mobile More panel;
- collapsed Admin rail icon repair;
- public, personal, auth and Admin cross-space flight transitions;
- reduced-motion fallback, RTL parity and API-ready service contracts.

## Preview boundary

All new records and mutations are device-local sample data. Production authorization must be enforced by authenticated APIs and database constraints. Do not ship the local adapter as a security mechanism.
