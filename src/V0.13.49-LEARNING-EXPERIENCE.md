# MedClub V0.13.49 — learning spaces and phone reading

This is the complete `src` directory, based on V0.13.48. Replace the existing `src` directory and retain the current project configuration and dependencies. All previous source files are included. Exam services, scoring, persistence, authentication and the future API adapter remain in place.

## Phone PDF reading space

The course frame follows the dynamic viewport and keeps only its small safe-area/edge inset. Phones use the existing previous/next actions in the PDF toolbar; the duplicate lower page-turn row no longer consumes 64px. The narrow toolbar uses one horizontal row, and an old 44px focus-mode spacer is removed on phones. Controls retain 44px touch targets. Very narrow course viewports are also allowed below the application's former 320px body minimum.

At a 320px-wide, 568px-high test viewport, the focused PDF toolbar measures 49px, the document viewport measures 459px, and the outer book ends 4px from the screen bottom. Normal reading mode retains its course/section navigation. Desktop side turns, single/two-page selection, zoom, notes, search, bookmarks, import, document proportions and internal pan/grab scrolling retain their existing behavior. None of these layout changes recreates the PDF document or worker.

## A journey through the homepage

The main campus hero is retained. The following sections now have different spatial layouts and interactions:

- **Curiosity road:** a curved, layered vector road connects numbered destinations, alternating sides on larger screens. Raised icon sculptures, entry lighting and brief waypoint sparks respond as a stop enters view. On phones, the route runs beside a readable single column of destinations. Arabic mirrors the route, cards and waypoints.
- **Student library:** vaulted outlines frame the existing leather 3D course books. Books sit on shelves; phones have a native swipe/snap shelf with previous/next controls. The Courses/Resources tabs, course destinations, catalogue count and resource collection are retained.
- **Campus events:** three real event tickets hang from a common display rail. They retain availability labels, dates, locations, capacity, links and saving. Their cutouts stay transparent across themes.
- **Opportunity doors:** curved doorway frames surround opportunity information. A restrained hinge/light effect appears on hover or keyboard focus. The full information area opens the opportunity; saving is a separate accessible button.
- **Journal edition:** a typographic magazine spread with three selectable stories. Selecting a story updates the cover, title, excerpt, author and destination with a brief page-entry transition. All information comes from the existing journal query.
- **Community commons:** the connected campus map has raised destinations and a layered center. Positions and connections mirror in Arabic.

The road and exam set piece are native vector/code artwork. No new raster downloads, WebGL scene, animation engine or dependency was added. New scroll reveals use the existing one-shot IntersectionObserver. Transitions are finite, content is visible by default, keyboard focus reveals its destination, and reduced motion bypasses the new movement.

## Exam presentation

The lobby has a new question-card set piece and color accents for recall, short practice and exam preparation. Course cards have binding-like edges and distinct accent colors. The setup modes use clearer selected states and consistent panels. On narrow screens, the artwork becomes a small accent so the first action remains visible; an unfinished session moves its resume action ahead of the introductory content.

Active sessions retain the dedicated full-screen environment. A question index, colored perimeter, progress treatment, clearer choices and distinct feedback states replace the previous uniform presentation. Reading tools use shorter labels. The question and answers keep a simple reading order and calm central surface. Recall keeps its real upcoming-card queue, two-sided flip, confidence ratings, scheduling and no-typing review behavior; its paper layers now have distinct tones.

The practice/self-test confirmation rules, editable/locked answers, flags, bookmarks, custom sets, saved attempts, results, reporting, printing, admin tools and API boundary are retained. This release changes their presentation rather than their data model or service contracts.
