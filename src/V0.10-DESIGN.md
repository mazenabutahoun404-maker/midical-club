# MedClub V0.10 design direction

## Concept: the clinical control room

Admin is a separate operational product, not a public page with extra buttons. The V0.10 shell shifts into a dark diagnostic environment while preserving the red/russet MedClub identity. Warm content surfaces sit inside a focused control plane so long review sessions remain readable.

## Signature behavior

- A restrained ECG signal, diagnostic rings and breathing control mark establish the admin world on arrival.
- Navigation icons run a short instrument-check motion on hover; active icons emit a quiet diagnostic ring.
- Metric cards expose their signal color through a fast scan instead of generic scale animation.
- Content review uses a queue-and-inspector workbench on large screens and a stable stacked flow on smaller screens.
- Activity history pairs searchable operations with a before/after inspector.
- Version comparison places the current and selected snapshots side by side; restoration explicitly creates a new version.
- V0.8 authentication remains the only WebGL surface. Admin motion is CSS-only and operational.

## UX rules

- Nothing moves directly from review to publication. Approval and publication are separate decisions.
- Requesting changes requires an explanatory note.
- Publication requires an approved state, confirmed rights and at least one reference.
- Activity history offers no edit or delete operation.
- Restoration preserves every previous version and appends a new audit event.
- Preview access is visibly separated from production authorization.
- The admin navigation follows the existing vertical/horizontal preference on larger screens and becomes a fixed horizontal dock on phones.

## Accessibility and responsive rules

- Every workbench preserves a linear DOM order: queue first, inspector second.
- Status is always represented by text, not color alone.
- Scrollable tab and navigation regions hide native bars without disabling touch, wheel or keyboard input.
- Mobile controls remain at least 44 px and form text remains zoom-safe.
- Logical properties and mirrored directional icons support Arabic RTL.
- `prefers-reduced-motion` removes scans, pulses, orbiting and hover displacement.

## Honest boundary

V0.10 demonstrates admin operations with device-local sample data. It does not implement production permissions. V0.12 remains responsible for capability enforcement, protected founders, high-risk approval and immutable server audit storage.
