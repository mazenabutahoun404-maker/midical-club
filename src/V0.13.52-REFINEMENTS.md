# MedClub V0.13.52

This is the complete source based on V0.13.51. Replace the project's existing `src` folder with the included folder. No dependency or API changes are required.

## Footer

The public footer returns to its original three-column layout, with the brand and two link columns. The existing route-specific building image is now a background inside the same content container. It fades into the surrounding theme colors at its edges and behind text. Separate solid panels and the phone's extra illustration area are removed. The personal footnote is compact again, with its scene behind its content. The site footer remains omitted from active course study and exam sessions.

The Octagram word uses a coral-to-gold-to-teal gradient drawn from the supplied logo. Light themes use deeper shades of those hues so the small wordmark stays legible; dark themes use brighter shades. The Instagram destination and external-link protections remain unchanged. Forced-colors mode falls back to normal readable link text.

## Course display

The large striped desk panel is replaced by a 38px walnut shelf beneath the books. It uses the project's existing subtle wood-grain asset, a shallow front edge and a restrained contact shadow. The books have a narrower maximum display width, leaving the library illustration visible around them. The library background stays behind the whole section. Phone browsing uses a native horizontal flex shelf with scroll snapping, the existing previous/next controls and language-aware movement. Resources remain a separate live tab.

## Phone navigation

More replaces the profile shortcut in the public and personal phone headers. Profile remains at the right end of the bottom dock; the desktop header retains its profile shortcut. More lists the current sidebar's main destinations, excludes the daily dock's destinations and removes duplicate URLs. Personal links share the desktop rail's source list. Nested sections, a second search field and duplicate profile/academic links are removed from the menu. Workspace switching and the capability-gated admin destination remain available to signed-in users. Appearance stays available in More.

The native dialog retains its close button, Escape handling, focus restoration and close-on-navigation behavior. The existing admin navigation is unchanged because its dock has its own administration menu and no duplicate profile shortcut.

## Reported console output

Vite connecting/connected and the React DevTools invitation are normal development messages. The failed `secure.similarweb.com` / `pro.similarweb.com` requests explicitly originate from the Similarweb sales extension. MedClub's source contains no Similarweb integration or those requests. Disable the Similarweb extension on localhost, or use an extension-free browser profile. The application cannot repair a third-party extension's authentication or remote CORS response.

`Could not establish connection. Receiving end does not exist` is consistent with extension messaging, but this unqualified line does not identify its source. Check its script URL before assigning it to a particular extension. No console errors are suppressed or hidden in this update.
