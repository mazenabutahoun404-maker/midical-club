# MedClub V0.13.20 — Shelf header and Learn hover

Based on the complete V0.13.19 source.

## Changes

- Removed the compound upward shift that moved both shelf books and their
  covers outside the clipped header. Book links stay in a stable frame; only
  the cover extends on hover/focus. The selected course retains its highlight.
- Kept a visible shelf lip inside the shelf window, with readable cover titles
  on touch screens. Course colors are retained, with darker gradient endpoints
  for sufficient contrast against the small cream labels.
- Reshaped the top-attached header with deeper left/right shoulders. The back
  link and study/appearance controls occupy inset areas within those shoulders.
  The central shelf remains deeper. Header height and the full reading area are
  retained, and smaller screens keep one named controls button and its flyout.
- Learn opens the existing learning panel on deliberate pointer hover. A short
  departure delay lets the pointer reach and use the panel; Escape dismisses it.
  Clicking Learn navigates directly to `/learn`, matching Explore every course.
  The category chevron and keyboard Arrow Down still open the panel. Touch
  activates the catalogue directly without requiring hover.
- Retained automatic campus-navigation hiding on course entry, Study focus,
  paper sections, the draggable/dockable toolbar, timer, course PDFs and
  permission-aware importing, personal notes, GPA and previous application routes.

## Verification

- 36 focused DOM interaction checks passed. These include both desktop menu
  orientations, hover-to-panel movement, direct Learn navigation, accidental
  hover dismissal, touch, keyboard, the screenshot's Biochemistry course,
  compact controls and the preserved course-navigation/toolbar checks.
- 66 CSS source-cascade scenarios and 20 contrast pairs passed. The shelf
  checks now include the combined parent/cover offsets against its clip window,
  rather than checking only the parent's height. They cover narrow phones,
  landscape, desktop, RTL, both themes and reduced motion.
- Strict TypeScript and the production build passed. No runtime dependency or
  media asset was added. The pre-existing shared-bundle advisory remains.

These checks do not establish rendered animation quality. Live browser visual
QA remains unverified because the Sites workflow requires skipping it when its
control-browser skill is unavailable in the managed environment. This release
does not claim a rerun of every historical feature suite.
