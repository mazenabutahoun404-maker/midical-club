# MedClub V0.13.46 — mental recall and a notebook within reach

This complete `src` folder extends V0.13.45. Replace your existing `src` folder and keep the current project configuration and dependencies. No dependency was added. Every previous source file, campus asset, course reader and exam administration feature is retained.

## Mental recall cards

The review flow is **read the question → answer in your mind → tap to flip → rate your recall**. There is no typing field or answer-choice selection during recall. The card can turn back to the question. Enter and Space activate the focused card. Reduced motion changes sides instantly.

Recall is a full option beside Practice and Self test on the question-set setup screen. Course question sets can be reviewed as cards, including the first question image where present. A finished attempt can supply its frozen questions; its focused recall selection includes wrong, skipped, flagged, unsure and guessed answers. Active self-test attempts do not expose a result-recall route.

Course recall rounds save their self-ratings and progress privately on this browser, keyed to the account, set/attempt and question versions. A completed round offers another round or a repeat of difficult cards. These self-ratings do not change the exam score or award campus progress.

The existing personal recall desk now uses the same card interface. It retains personal card creation/editing, course filters, the existing review scheduling service, deletion/undo and saved collections. Students can open a card from the collection for additional review. Card creation has question and answer fields; reviewing a card has none. PDF-derived cards retain a source-page link.

## A clearer exam experience

- The entrance offers Continue my session / My recall cards, I have 5 minutes, and Prepare for an exam. Quick setup supports Practice, Self test and Recall, using only questions available in the selected course. The five-minute action starts a short set; it does not promise a fixed completion time.
- Practice first saves an unconfirmed selection. **Check answer** commits it and reveals feedback. An accidental tap can be changed before confirmation. Unchecked selections remain skipped when finishing, and survive save/resume as selections.
- Optional confidence tags distinguish Confident, Unsure and Guessing. They are saved independently of answer correctness and appear in the next-review selection and chapter summaries.
- The active question has selected-text highlighting, reversible choice crossing-out, larger text and a hide/show timer. These reading aids do not change scoring. Text highlighting and crossing-out are temporary aids for the current rendered question.
- Results offer a focused recall round and chapter counts for missed/skipped and uncertain/guessed questions, alongside the existing score, filters and explanations.
- Paper arrival, answer feedback, card turning/dealing and small button responses use short CSS transitions. No perpetual render loop, WebGL dependency, screen-wide flash or animated image blur was added. Mobile page controls follow the question content without covering answer rows.
- Save and exit waits for the save and prevents a redundant cleanup save. Finished attempts enter the query cache before navigating to results, preventing an active cached attempt from redirecting the result view. Timer updates remain separate from the question tree.

## Notes in every header

Public, personal, admin and authentication headers now offer **My notes** in the former language-control position. Language switching remains in Appearance and is available to guests and signed-in accounts.

The new nonmodal notebook reuses the existing private general/course PDF notes workspace and its save, validation, color, attachment and navigation behavior. It stays mounted while hidden or while navigating, keeping the current editor draft. Hiding folds it to a small edge tab; either the tab or header reopens it.

Drag the grip to move the notebook, or focus the grip and use arrow keys. Shift plus arrows makes larger movements; Home or the reset button returns it to a useful position. Position is saved per account and clamped to the available viewport. The panel has its own scrollbar, adapts to small screens/visual viewport changes, and clears mobile navigation. Escape hides it when no modal is open. It is excluded from printing. Signing out or changing accounts replaces the notebook instance so another account cannot see the editor.

Hiding the panel preserves an in-memory editor; it does not turn an unsaved draft into a server record or guarantee recovery after closing the browser. Saved notes continue to use the pre-existing note services/device storage.

## Guest theme discovery

Guests see all 19 appearance choices: MedClub Light and Dark remain usable; the other 17 display a lock and sign-in wording. Hover/focus can show a read-only preview. Clicking a locked choice explains the requirement and provides Sign in to unlock, without changing the active palette. Signed-in users retain full theme selection. The existing guest palette restriction remains enforced in `AppearanceProvider`, in addition to the UI.

## API compatibility

Exam APIs remain disconnected. The V0.13.45 service adapter boundary and clearly labeled local preview remain in place. `ExamProgress` adds optional `pendingAnswers` and `confidence` records; old attempts without them still load. A future adapter must preserve these fields and exclude pending answers from grading. See [integration/EXAMS-FRONTEND.md](./integration/EXAMS-FRONTEND.md).

Personal recall still uses the existing `StudyHubService` contract. Course recall rounds use a separate device-local teaching state; neither format introduces original med-exam API routes or credentials.
