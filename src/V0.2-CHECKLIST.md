# V0.2 implementation and verification

Release: V0.2 Academic Core · 3 September 2026.

## Implemented

- Academic gateway with Basic and Clinical portals, live counts and global course search entry.
- Three bilingual sample batch homes with progress, current term and previous-term archives.
- Fourth-, fifth- and sixth-year clinical pages with current focus, focus areas and mapped courses.
- Seventeen bilingual courses with credits, semester, outcomes, updated date, accent and ordered section configuration.
- Twenty-five bilingual sample materials across eight resource types.
- Shared and batch-specific audience metadata.
- Course atlas with Overview, Guidance, Slides, Notes, Summaries, Recordings, Books, Questions and External sections.
- Course-specific visual branding and reusable public/personal course routes.
- New responsive academic layouts, hover effects, pointer light, entry transition and reduced-motion support.
- API-ready service methods and query hooks for batches and clinical years.
- Updated interface copy in English and Arabic.

## Known limitations

The initial JavaScript bundle remains above Vite's 500 kB advisory threshold (about 673 kB minified and 212 kB gzip). Route pages are lazy-loaded, but the service registry and shared UI dependencies remain in the initial bundle. Production performance tuning should split vendor/data adapters after the integrating app's deployment target is known.

Real-browser visual acceptance at 360/768/1024/1280/1536 px, browser zoom, Safari/Firefox and screen-reader behavior could not be verified in this environment. Component tests do not verify CSS geometry. No WCAG certification or cross-browser acceptance claim is made.

All academic records and materials are samples. There are no attached PDFs, recordings or external links. Authentication, backend authorization, uploads, scientific approval, curriculum administration and account synchronization remain unimplemented.
